# App-VestaAlarm-Aris-868-2
Unabhängige Android-App zur SMS-Steuerung einer kompatiblen VESTA ARIS 868/2 Alarmanlage. Vollscharf, Zuhause und Unscharf schalten, Status abfragen, Antworten der Anlage lesen sowie Einstellungen und Komponenten verwalten. Die Bedienoberfläche orientiert sich an einer Fernbedienung und hebt den zuletzt bestätigten Zustand hervor.
 Einstellbare Antwortwartezeit, mehrere Zentralen und Sammel-SMS werden unterstützt.
Android ab Version 8.0; aktive SMS-fähige SIM, eigene Alarmanlage und deren Zugangsdaten erforderlich. SMS-Gebühren können anfallen. Keine Werbung, keine App-Cloud, kein Tracking. Die App nutzt keine Internetberechtigung. Sie benötigt Berechtigungen zum Senden und Empfangen von SMS. PIN und Keyword werden im SMS-Text an die Anlage übertragen.
Mit Unterstützung künstlicher Intelligenz entwickelt. Keine offizielle Hersteller-App. Keine garantierte Alarmüberwachung oder Notruf-Funktion; Telefonalarme werden nicht automatisch angenommen.
